# roombapy-prime 0.9.1

**The Roomba j8+ is a Classic robot.**

The SKU table tells the two robot generations apart. `j855020`, a Roomba
j8+, was not in it: unknown, it took the Prime path when it was added
from the iRobot account, and was set up cloud-only, without the local
connection a j7 gets. Its firmware (`sapphire` 24.29.3) is the j7's
platform. SKUs starting with `J8` are Classic now; no Prime SKU starts
with them.

A robot already set up cloud-only keeps that setup until the caller
moves it; in Roomba+, *Reconfigure* with the robot's IP address does.

## Tested

- The library's suite and the tools' suite pass; ruff, strict mypy and
  the per-module coverage floors pass.
- The field-device test has the j8+, and fails without the entry.
