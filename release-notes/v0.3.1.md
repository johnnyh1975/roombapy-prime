# roombapy-prime 0.3.1

Two corrections to the room listing, both from @chairstacker running
0.3.0 within the hour.

## Every zone was marked as possibly deleted

0.3.0 added a marker for entries the snapshot still carries but the
current map version does not — a deleted zone, in other words.

It compares against `geojson_details.regions`, which lists **rooms**.
Zones are not in it, so every zone qualified and all ten of his were
flagged.

A marker that always fires is not information. It applies to rooms
only now.

The honest position for zones is that there is no list of what
currently exists, so a deleted zone and an unnamed one still look
alike. That is worse than being able to tell them apart and better than
claiming to.

## A bundle-listed zone showed no type

Zone 109 appeared — the fix in 0.3.0 worked — but as
`region_type=None`, because the snapshot has no entry to read a type
from.

A name found in the bundle's zone layers is itself the answer, so it
reads `'zid (from bundle)'` rather than looking like missing data.
