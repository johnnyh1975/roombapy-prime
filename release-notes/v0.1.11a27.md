# v0.1.11a27

The region-command question is answered.

## `initiator` is required

A stored favorite does not carry one; the app adds it when sending. Without it, the command is
delivered, acknowledged, and quietly ignored.

This took three rounds to establish, and the reason is worth recording: two earlier runs appeared
to refute it, and both were confounded by sends that never reached the broker. Only once the
connection work landed did a run produce three stages with confirmed delivery — at which point the
comparison was finally fair. Stage 1 without an initiator left the robot on `charge`. Stage 1b,
identical but for that one field, started a mission.

## The from-scratch command was wrong in three ways

Stage 3 was written when nothing worked at all, and was never reconciled with the shape that
later turned out to work:

| | working | stage 3 |
|---|---|---|
| command | `start` | `clean` |
| region key | `region_id` | `id` |
| map version | present | absent |

The first two are fixed. The region key had been an open question recorded in the code itself —
reads showed `region_id`, writes assumed `id` — and field data settles it: both working commands
carried `region_id`, and the robot echoed them back unchanged.

## Virtual-wall writes sent one point too many

A GeoJSON ring repeats its first coordinate as its last, so a rectangle read from the map bundle
arrives with five points. The wire format takes four. Resending two untouched zones returned
HTTP 500.

The correct format was already documented in this project's own code, directly above the function
that got it wrong.

## The map-version warning was noise

Real mission events show the robot re-versioning its map five times inside 37 seconds of cleaning.
Every stored favorite is therefore stale within a minute of being saved, and two confirmed-working
commands carried versions hours out of date. It now reports as expected rather than as a failure —
noise beside genuine failures makes those easier to miss.

## Also confirmed

Zone types, against real data rather than decompilation alone: `1 = KeepOutZone`, `6 = NoMopZone`.

811 tests passing, ruff clean.
