# v0.1.11a28

Mostly one thing: turning the virtual-wall failure from a guessing game into an experiment.

## The a27 fix was real, and was not the cause

a27 corrected a genuine format deviation — a GeoJSON ring repeats its first coordinate as its last,
so rectangles were going out with five points where the wire format takes four.

A field retest confirmed the payload is now correct **and still returns HTTP 500**. So that
deviation was real, and demonstrably not what the server was choking on. Worth stating plainly:
the obvious explanation was wrong.

## The next suspect was documented as unverified all along

What actually goes on the wire is not what the script prints. The command sits inside an envelope:

```json
{"edit_cmd": { …the command… }, "response_type": "link"}
```

`"link"` asks the server for a presigned **download** URL. That is confirmed for *fetching* a map;
on an *edit* it may be meaningless — which fits a body that parses and then cannot be honoured.
This method's own docstring has said "not confirmed, honestly not verified" since it was written.

## So the script now tests instead of guessing

`--update-unchanged` tries three request shapes in a single run, stopping at the first success:

1. `response_type` omitted entirely
2. `"link"` — the previous default
3. `"binary"`

The command body is byte-identical across all three, so a variant that works implicates the
envelope and nothing else.

**If all three fail, that is also a result.** It rules out `response_type` and moves the suspicion
to the discriminator inside `edit_cmd` — the other item the same docstring flags as unconfirmed.

Testing one guess per round is too slow when each round costs a tester their evening.

## Also confirmed from the field

- **SKU prefix `Y41`** seen on real hardware for the first time. Three of fifteen prefixes in the
  table are now field-confirmed rather than decompilation-only.
- **Five capability flags were being silently dropped** — `cmds`, `eCmd`, `mopLift`, `odoa`,
  `p2maps_editv2_feats`. That object is the only place describing what a *specific* device can do,
  and it drives feature gating: a capability we never see is a feature we can never offer. A guard
  test now names any capability from a real capture that the model does not declare.

819 tests passing, ruff clean.
